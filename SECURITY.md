# Security Policy

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability in the Token Helper project, please report it responsibly.

**Please do not open a public GitHub issue for security vulnerabilities.**

### How to Report

Email your security concern to: **[your-security-email@example.com]**

Include:
- Description of the vulnerability
- Steps to reproduce (if applicable)
- Potential impact
- Suggested fix (if you have one)
- Your contact information

We will acknowledge receipt of your report within 48 hours and work with you to resolve the issue.

## Security Best Practices

When using Token Helper:

1. **Keep your tokens secure** - Never share authentication tokens with untrusted sources
2. **Use official releases** - Download from the official GitHub Releases page only
3. **Keep dependencies updated** - We regularly update Python dependencies for security
4. **Review the code** - This is open source - feel free to audit it before using
5. **Use on trusted computers** - Only run this on systems you control and trust

## Supported Versions

Security updates will be provided for:
- Current release (v1.x.x)
- Previous major version during transition period

## Security Headers

This project follows security best practices:
- All GitHub Actions are signed and verified
- Dependencies are scanned for vulnerabilities
- Code is reviewed before merging

## Disclaimer

This tool is provided **for authorized use only**. Users are responsible for:
- Complying with Discord's Terms of Service
- Following local laws and regulations
- Only using on systems they own or have permission to access

## Acknowledgments

We appreciate the security researchers and community members who responsibly disclose vulnerabilities.
